# Cartilha Comercial Sangfor

Guia de vendas interativo para o **time comercial**. Funciona como um site simples que
abre no navegador — sem instalar nada.

## O que tem dentro

- **📦 Produtos** — cada solução Sangfor explicada em linguagem simples
- **🧰 Catálogo (Modelos)** — modelos de firewall por porte de cliente (nº de usuários)
- **💢 Dores → Solução** — ouviu a dor do cliente? Veja a solução e o que dizer
- **🔄 Trocar p/ Sangfor** — como propor a troca de um concorrente (VMware, Fortinet, etc.)
- **🛡️ Objeções** — respostas prontas para "é caro", "já tenho fornecedor", etc.
- **🎤 Pitch Rápido** — roteiro de 5 passos para conduzir a conversa
- **🏆 Casos de Sucesso** — resultados reais para usar como prova social
- **⭐ Diferenciais** — por que escolher a Sangfor

## Como abrir

Basta abrir o arquivo `index.html` no navegador (clique duplo).

## Como editar o conteúdo (sem saber programar)

Todo o texto (produtos, dores, objeções, modelos) fica no arquivo **`data.js`**.
Abra com qualquer editor de texto, encontre o bloco que quer mudar e troque o texto
entre aspas. Salve e recarregue a página.

## Publicar online para o time (GitHub Pages)

Veja o passo a passo em **`COMO-PUBLICAR.md`**.
